# עד הזריחה

משחק עלילתי קולנועי בגוף ראשון, בשתי גרסאות: **דפדפן** (Three.js, מולטיפלייר) ו-**Roblox** (Luau + Rojo).
המשחק מבוסס בחלקו על סיפורים אמיתיים מהשבעה באוקטובר. הדמויות בדיוניות ומורכבות מכמה סיפורים.
זהו משחק תחרות פרטי שנוצר לחברים, מתוך כבוד וזיכרון.

> **לזכר הנרצחים, לרפואת הפצועים, ולשובם של כל החטופים**

## גרסת דפדפן (`/web`)
**הפעלה מקומית:**
```bash
cd web && python3 -m http.server 8080
```
ואז לפתוח את `http://localhost:8080`.

**העלאה ל-MOLTY PLAYER:** מעלים את כל תוכן התיקייה `web` (כולל `index.html`, `style.css`, `dist/` ו-`assets/`). הכניסה היא דרך `index.html`, ואין צורך בשרת. הקובץ `dist/game.js` כבר בנוי ומחויב ל-repo.

**בנייה מחדש אחרי שינוי קוד:**
```bash
cd web && npm install && npm run build
```

**מולטיפלייר:** בחרתי ב-**WebRTC דרך PeerJS**, כי זה עובד מאחסון סטטי לחלוטין, בלי שרת ובלי מפתחות (שרת האיתות הציבורי של PeerJS רק מחבר בין הדפדפנים, והמשחק עובר ישירות ביניהם). המארח הוא הסמכות לעלילה, לפאזלים ולמעברי פרקים. לחדר יש קוד בן 5 תווים וקישור הזמנה להעתקה. כש"חברים בלבד" מופעל, נוצר גם קוד נעילה שנכנס לקישור. שיתוף פעולה בלבד, בלי PvP.

**אדמין:** F9. הסיסמה נמצאת ב-`web/src/config/game.config.js` (`adminPassword`). אחרי שינוי מריצים `npm run build`.
**מצב בדיקה:** `index.html?dev=2&cp=escape` מדלג על האזהרה ועל הלובי ומתחיל ישר מפרק או מצ'קפוינט.

**שליטה:** WASD לתנועה, Shift לריצה, Ctrl/C להתכופפות, E לאינטראקציה, Q לריקוד, F לסלפי, L לפנסי רכב, Tab לטבלת ניקוד, Esc להשהיה.

## גרסת Roblox (`/roblox`)
1. מתקינים את [Rojo](https://rojo.space) ואת התוסף שלו ל-Studio.
2. מריצים:
```bash
cd roblox && rojo serve
```
3. ב-Studio: Plugins ← Rojo ← Connect.
4. ל"חברים בלבד" (ReservedServer): מפרסמים את המקום ומגדירים את `GamePlaceId` ב-`src/shared/Config.lua`. מוסיפים אדמינים ב-`AdminUserIds`.
