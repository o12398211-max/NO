# עד הזריחה

משחק עלילתי קולנועי בגוף ראשון, בשתי גרסאות: **דפדפן** (Three.js, מולטיפלייר) ו-**Roblox** (Luau + Rojo).
המשחק מבוסס בחלקו על סיפורים אמיתיים מהשבעה באוקטובר. הדמויות בדיוניות ומורכבות מכמה סיפורים.
זהו משחק תחרות פרטי שנוצר לחברים, מתוך כבוד וזיכרון.

> **לזכר הנרצחים, לרפואת הפצועים, ולחיזוק החטופים ששבו הביתה ומשפחותיהם**

## גרסת דפדפן (`/web`)
**הפעלה מקומית:**
```bash
cd web && python3 -m http.server 8080
```
ואז לפתוח את `http://localhost:8080`.

**העלאה ל-MOLTY PLAYER:** מעלים את כל תוכן התיקייה `web` (כולל `index.html`, `style.css`, `dist/` ו-`assets/`). הכניסה היא דרך `index.html`, ואין צורך בשרת. הקובץ `dist/game.js` כבר בנוי ומחויב ל-repo.

**בנייה מחדש אחרי שינוי קוד:**
```bash
cd web && npm install && npm run build
```

**מולטיפלייר:** בחרתי ב-**WebRTC דרך PeerJS**, כי זה עובד מאחסון סטטי לחלוטין, בלי שרת ובלי מפתחות (שרת האיתות הציבורי של PeerJS רק מחבר בין הדפדפנים, והמשחק עובר ישירות ביניהם). המארח הוא הסמכות לעלילה, לפאזלים ולמעברי פרקים. לחדר יש קוד בן 5 תווים וקישור הזמנה להעתקה. כש"חברים בלבד" מופעל, נוצר גם קוד נעילה שנכנס לקישור. שיתוף פעולה בלבד, בלי PvP.

**אדמין:** F9. הסיסמה נמצאת ב-`web/src/config/game.config.js` (`adminPassword`). אחרי שינוי מריצים `npm run build`.
**מצב בדיקה:** `index.html?dev=2&cp=escape` מדלג על האזהרה ועל הלובי ומתחיל ישר מפרק או מצ'קפוינט.

**שליטה:** WASD לתנועה, Shift לריצה, Ctrl/C להתכופפות, E לאינטראקציה, Q לריקוד, F לסלפי, L לפנסי רכב, Tab לטבלת ניקוד, Esc להשהיה.

## גרסת Roblox (`/roblox`)
גרסה מלאה בת 6 פרקים ב-Luau, מסונכרנת ל-Studio עם Rojo.

### פתיחה ב-Studio
**דרך מהירה:** פותחים ב-Studio את הקובץ `roblox/build/AdHazricha.rbxl`, שנבנה מהפרויקט באמצעות Rojo.

**סנכרון חי לעבודה על הקוד:**
1. מתקינים את [Rojo](https://rojo.space) ואת התוסף שלו ל-Studio.
2. מריצים:
```bash
cd roblox && rojo serve
```
3. ב-Studio: Plugins ← Rojo ← Connect.

**בנייה מחדש של הקובץ:**
```bash
cd roblox && rojo build -o build/AdHazricha.rbxl
```

### לפני פרסום (Publish)
1. File ← Publish to Roblox.
2. Game Settings ← Security ← להפעיל **Enable Studio Access to API Services**. זה נדרש לשמירת VIP ב-DataStore.
3. "חברים בלבד" (שרת פרטי דרך ReservedServer) והמעבר לשרתים עובדים רק במקום שפורסם, לא בתוך Studio. ב-Studio המשחק פשוט מתחיל באותו שרת.

### מה יש בגרסה
- **אזהרת טריגר** לפני הכול, עם שלושה מתגים: הפחתת אפקטי פחד, הפחתת הבהובים וכתוביות גדולות.
- **לובי:** אולם מכובד עם קיר זיכרון ונרות, וארבעה עיגולים על הרצפה (2/4/6/8 שחקנים). בכניסה לעיגול נפתח חלון: גודל שרת, "חברים בלבד" וכפתור התחל. בלובי בוחרים גם שם, פנייה, גוון עור, שיער, בגדים, או להשתמש באוואטר האישי.
- **פרק 1 – המסיבה:**
  - קאטסין פתיחה, ואחריו כ-45 שניות חופשי.
  - שיחות, מיני־משחקי קצב, תופים וסלפי.
  - שחר והצמיד. אם השחקן לא מוצא אותה, היא מגיעה אליו.
  - מופע במה מסונכרן: קיר LED מונפש, קרני אור ולייזרים, ובכל דרופ זיקוקים, קונפטי, להבות ו-CO2.
  - כל רוקד רוקד אחרת.
  - אחורי הקלעים (VIP), ואחר כך פיזור לאוהלים ושינה.
- **פרק 2 – הבוקר, הבריחה והתפיסה:**
  - אזעקה, ורקטות ויירוטים בשמיים.
  - כ-150 אנשים נמלטים, כל אחד לכיוון אחר.
  - שחר נבלעת בהמון.
  - חפירה בחול ואקדח, ואז חובה להפיל 3 מחבלים.
  - האקדח עף ונעלם.
  - חלון בריחה מוגן (תחושת "הצלחתי"), ואז תפיסה מבהילה שמותאמת למסלול: רגלית, ברכב או במסתור.
  - כל זה בלי טקסט על המסך.
- **פרק 3 – המנהרה:** פענוח קוד טפיחות, מאיר והכלי (בחירת אמון), עידו והמנגינה. הצינורות דורשים שני שחקנים שונים כשמשחקים ביחד. אחריהם סטלת' בין פנסים, ואז הסורג והפיר.
- **פרק 4 – בחוץ:** קאטסין המפה בגוף שלישי, מיני־מפה עגולה עם מסלול, רכבים ואופנוע, ופנסים (L) שמסגירים אותך. סיורים עם פנסים, ובסוף תפיסה מפתיעה כשכל הפנסים נדלקים בבת אחת.
- **פרק 5 – המטוס:** שחר והצמיד התאום, בקשת אישור מהמחבל, ואז השירותים (החלון, המגירה, האקדח, השריקה). שחקנים אחרים מופיעים כרוחות שקופות.
- **פרק 6 – הבית:** הירייה (המצלמה מסיטה מבט, בלי פרטים גרפיים), צביקה והמצנח, המשואה, הדלת, הצניחה, הנחיתה בישראל, האיחוד, אפילוג בכיכר, הקדשה וקרדיטים.

### פאנל אדמין
- זמין רק למשתמש **9214350185**: מופיע לו כפתור קטן 🔨 בפינה, והשרת בודק את המזהה בכל פקודה.
- **כתובת הקוד:**
  - את מזהה האדמין משנים ב-`roblox/src/shared/Config.lua` (`AdminUserId`).
  - הפקודות עצמן ב-`roblox/src/server/Main.server.lua`.
  - ממשק הפאנל ב-`roblox/src/client/AdminPanel.lua`.
- **הכרזה גלובלית:** בעיצוב של פס עם שם אדום ווי כחול.
- **הודעת שרת קבועה.**
- **סקר:** עד 4 אפשרויות, טיימר והצבעה חיה.
- **אירועים לזמן מוגבל:** דיסקו, זיקוקים, דרופ, קונפטי והחשכה.
- **פקודות שחקן:** לפי שם או שם תצוגה, או me / others / all. קיק, באן, אזהרה, השתקה.
- **מתנות:** VIP לאחורי הקלעים לפי שם משתמש (נשמר ב-DataStore), רובה אדמין קבוע (פוגע רק במחבלים, אין PvP), מהירות, קפיצה, צמיד.
- **ג'אמפסקייר של מחבל:** לשחקן מסוים או לכולם. אצל מי שהפעיל "הפחתת אפקטי פחד" הוא מופיע בעדינות.
- **טלפורט:** אליי, אל שחקן, לבמה, לאחורי הקלעים, לאוהל, ללובי.
- **"עוד…":** דילוג לפרק, צ'קפוינטים, שעה ביום, אויבים, ללא פגיעה, FPS, הסתרת UI, טיסה.
